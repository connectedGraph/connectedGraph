## 🌐 Public APIs @ [6767.chat/api/docs](https://6767.chat/api/docs)

> 个人站点公开的 API 接口，欢迎调用 ✨

```
GET  https://6767.chat/api/shizuku/image          → Shizuku 图片词表
GET  https://6767.chat/source/shizuku/{name}       → 获取对应图片
GET  https://6767.chat/api/tts-proxy/google        → Google TTS 中转
POST https://6767.chat/api/tts-proxy/mimo          → MiMo TTS 中转
POST https://6767.chat/api/speech-score            → 有道语音评测中转
GET  https://6767.chat/api/playground/lab-schedule → 实验室课表查询
POST https://6767.chat/api/ask                     → Claude 知识库问答
```

### 🎨 Shizuku 随机图

```bash
# 获取图片单词列表
curl "https://6767.chat/api/shizuku/image"

# 用词条直接访问图片
curl "https://6767.chat/source/shizuku/Angel" -o shizuku.jpg
```
